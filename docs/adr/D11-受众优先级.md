# D11: 受众优先级：通用 / 独立开发

- **状态**: 已采纳
- **日期**: 2026-10

## 背景

自托管 + 完整闭环最能体现工程深度：从平台适配到转写到 LLM 加工到笔记落盘，全链路自研。Java 提前上马反而拖慢闭环，因为 Playwright / faster-whisper 在 Java 侧不成熟。阶段 6 的 Java 控制面作为「可选项」展示分布式能力，而非主线。

## 决策

作品集的读者定位为通用工程岗位评审者和独立开发者，不是 Java 后端专岗或 AI/Agent 专岗。

## 备选方案

1. 定位 Java 后端岗——Java 控制面应是主线而非可选，但那样 Python 数据面会被边缘化。2. 定位 AI/Agent 岗——需要 RAG / 向量库 / Agent 框架，当前项目不涉及。3. 定位通用/独立开发——已采纳，两条线都展示。

## 推翻条件

转向 Java 后端岗或 AI / Agent 岗作品集时，需调整侧重点和补充对应能力。
