# 知记工作台 · 外部依赖清单

> 版本：v0.1（2026-10-26） · 列出工作台对「机器外部服务 / 工具」的依赖，以及缺失时的降级

## 一、必装的本机工具

| 工具 | 用途 | 缺失影响 |
| --- | --- | --- |
| **FFmpeg** | 媒体工坊转码 / 裁剪 / 导出；Whisper 抽音频 | 媒体工坊全部功能不可用；视频解析仍可抓字幕但无法处理音视频 |
| **faster-whisper**（Python 包，已装） | 语音转字幕 | ⑤ 字幕生成、① 无字幕视频转写不可用；有字幕的视频解析不受影响 |

## 二、外部在线服务

| 服务 | 用到它的工作区 | 缺失 / 失效时降级 |
| --- | --- | --- |
| **LLM API（兼容 OpenAI 协议）** | ① 笔记生成、④ 文档助手全部、③ 知识库问答 | 工作台核心智能能力全部停摆；笔记只能存原文、不能成稿、不能问答。这是最关键依赖 |
| **平台登录态（Cookie）** | ① 视频解析（抖音 / B 站 / 知乎 / 小红书） | 对应平台解析失败；其余平台不受影响。已有凭据健康检查提示过期 |
| **平台本身可访问性** | ① 视频解析 | 平台风控 / 下线对应内容时单条失败，不影响其他工作区 |
| **向量检索后端（本机内嵌）** | ③ 知识库语义检索 / 问答 | 向量检索降级为纯全文检索（FTS5），问答仍可基于全文命中文块 |

## 三、可选外部依赖（第二版再考虑）

- 对象存储（S3 / OSS）：第一版用本地文件卷，**不接**。
- 托管向量库（Pinecone 等）：第一版用本地内嵌，**不接**。
- 邮件 / 推送通道：提醒第一版用本机轮询 + 前端提醒，**不接外部推送**。

## 四、降级原则

任何外部服务失效，工作台**不整体崩溃**，只让对应能力降级或置灰，其余工作区照常用。界面应在对应入口给出「依赖不可用」提示，而不是报错整页。
