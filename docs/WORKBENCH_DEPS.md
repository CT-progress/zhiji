# 知记工作台 · 外部依赖清单

> 版本：v0.2（2026-10-27） · 当前已落地工作区 ①–③，④⑤仍按计划。

## 一、本机工具

| 工具 | 用途 | 缺失影响 |
| --- | --- | --- |
| **FFmpeg** | 媒体工坊转码 / 裁剪 / 导出；Whisper 抽音频 | 目前只影响尚未实现的 ⑤；视频解析有字幕时仍可用 |
| **faster-whisper** | 语音转字幕 | 无字幕视频转写不可用；有字幕的视频解析不受影响 |
| **SQLite** | 笔记、待办、知识库与任务数据 | 通过 SQLAlchemy 内置支持，无需单独服务 |
| **进程内哈希向量** | 知识库混合检索 | 不依赖外部向量库；代码与数据都在本机 |

## 二、外部在线服务

| 服务 | 用到它的工作区 | 缺失 / 失效时降级 |
| --- | --- | --- |
| **LLM API（兼容 OpenAI 协议）** | ① 笔记生成、③ 资料问答、未来 ④ 文档助手 | 笔记生成与资料问答停用；知识库导入、阅读、检索仍可用 |
| **平台登录态（Cookie）** | ① 视频解析 | 对应平台解析失败；其余平台不受影响 |
| **平台本身可访问性** | ① 视频解析 | 平台风控 / 内容下线时单条失败，不影响本地笔记与知识库 |

## 三、明确不接的外部依赖

- 对象存储（S3 / OSS）：第一版用本地文件卷。
- 托管向量库（Pinecone / Chroma 服务）：当前使用 SQLite 中的稳定哈希向量，无独立服务。
- 邮件 / 推送通道：提醒后续先用本机轮询与站内提示。
- 内置大模型推理：LLM 统一走外部兼容端点。

## 四、降级原则

任何外部服务失效，工作台不整体崩溃，只让对应能力降级或置灰，其余工作区照常使用。界面应给出依赖不可用提示，而不是整页报错。
