# 知记工作台 · 外部依赖清单

> 版本：v0.3（2026-10-27） · 当前已落地工作区 ①–⑤ 的 MVP。

## 一、本机工具

| 工具 | 用途 | 缺失影响 |
| --- | --- | --- |
| **PyAV** | 媒体探测、抽音轨、MP4 转码、裁剪 | 媒体处理不可用；通过主依赖 `av>=14` 随项目安装 |
| **faster-whisper（可选）** | 语音转字幕 | 媒体字幕与无字幕视频转写不可用；有字幕的视频解析不受影响 |
| **SQLite** | 笔记、待办、知识库、文档与任务数据 | 通过 SQLAlchemy 内置支持，无需单独服务 |
| **进程内哈希向量** | 知识库混合检索 | 不依赖外部向量库；代码与数据都在本机 |

> 媒体工坊**不依赖系统 FFmpeg 可执行文件**。转码、裁剪和抽音轨由 PyAV（FFmpeg 库绑定）在 Python 进程内完成。

## 二、外部在线服务

| 服务 | 用到它的工作区 | 缺失 / 失效时降级 |
| --- | --- | --- |
| **LLM API（兼容 OpenAI 协议）** | ① 笔记生成、③ 资料问答、④ 文档 AI 协作 | 三类生成能力停用；笔记、知识库导入阅读检索、文档 CRUD / 自动保存 / 取材 / 导出、媒体工坊仍可用 |
| **平台登录态（Cookie）** | ① 视频解析 | 对应平台解析失败；其余平台不受影响 |
| **平台本身可访问性** | ① 视频解析 | 平台风控 / 内容下线时单条失败，不影响本地笔记与知识库 |

## 三、明确不接的外部依赖

- 对象存储（S3 / OSS）：第一版用本地文件卷。
- 托管向量库（Pinecone / Chroma 服务）：当前使用 SQLite 中的稳定哈希向量，无独立服务。
- 邮件 / 推送通道：提醒后续先用本机轮询与站内提示。
- 内置大模型推理：LLM 统一走外部兼容端点。

## 四、降级原则

任何外部服务失效，工作台不整体崩溃，只让对应能力降级或置灰，其余工作区照常使用。界面应给出依赖不可用提示，而不是整页报错。

媒体工坊的降级边界：未安装 `faster-whisper` 时只禁用字幕生成；图片 / 音频 / 视频上传预览、搜索重命名、抽音轨、转码、裁剪、下载与删除仍可用。
