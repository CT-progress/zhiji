# 知记工作台 · 产品定位

> 版本：v0.2（2026-10-27） · 形态：本地智能工作台第一版 · 后续：第二版可向 SaaS 演进

## 一句话定位

知记从「单平台视频转笔记工具」升级为**面向个人使用的本地智能工作台**——一个本机运行的统一界面，把碎片化的内容加工（视频解析、笔记、待办、知识库、文档处理、媒体处理）收拢到一处，所有数据留在本地，不依赖云托管。

## 给谁用

- **独立创作者 / 自学者 / 知识工作者**：日常有大量视频、文档需要整理成可检索、可复用的笔记与知识库。
- **单人或小范围自托管用户**：在一台机器上自己用，不对外开放注册。
- **后续演进**：第二版按需开放多租户、走向 SaaS，但第一版不为此做架构妥协。

## 解决什么

- 内容散落各处：视频在平台、笔记在 Obsidian、待办在另一个 App、文件在网盘，互相找不回来。
- 加工链条断裂：抓取、转写、成稿、入库分属不同工具，每次都要手动搬运。
- 资料无法问答：本地文件只能按文件名找，不能语义检索、不能基于资料问答。
- 媒体处理零散：字幕提取、音频转码、片段裁剪要开几个工具来回切。

知记把这些动作收拢到**一个本机界面**，共享同一套任务编排、同一套知识库、同一套凭据管理。

## MVP 包含哪几个工作区

| 工作区 | 能力（MVP 范围） |
| --- | --- |
| **① 视频解析** | 已有的多平台视频解析成笔记链路（抖音 / B 站 / 知乎 / 小红书），保留不动 |
| **② 笔记与待办** | 笔记 CRUD、任务 / 提醒 / 日程、习惯打卡；笔记可一键来自视频解析产物 |
| **③ 知识库** | 项目资料库、本地文件上传、文档解析、全文检索、向量检索、基于资料的问答；自动导入知记生成的笔记 |
| **④ 文档助手** | 总结 / 问答 / 内容生成 / 校对润色 / 批处理 / 格式转换与导出；输入源可为知识库文档或本地文件 |
| **⑤ 媒体工坊** | 图片 / 音视频上传预览、字幕生成（Whisper）、FFmpeg 处理、异步导出 |

五个工作区共享同一后台进程、同一数据库、同一任务队列、同一份用户隔离与凭据加密。

## 明确不做什么（防越界，硬约束）

以下在第一版**坚决不做**，写下来防后期范围漂移：

- ❌ **不做对外开放注册的 SaaS**。第一版只服务本机一个或几个账号；多租户、计费、备案、公网 TLS 留到第二版。
- ❌ **不做移动端原生 App**。响应式 Web 即可。
- ❌ **不做桌面端打包（Electron / Tauri）**。当前形态是「本地前后端一体起」，桌面化是后一步。
- ❌ **不做分布式 / 集群 / 多机房**。单机进程 + 本地数据库 + 本地文件卷就够。
- ❌ **不做微服务拆分**。单体模块化没做透之前不拆服务。
- ❌ **不继续扩张抓取平台**。4 个平台已证明适配器可扩展，第 5 个只增维护成本。
- ❌ **不做对象存储服务（MinIO / S3）**。本机用具名文件卷即可。
- ❌ **不做团队协作 / 共享 / 权限树**。单人 / 自托管场景不需要。
- ❌ **不做内置大模型推理**。LLM 一律走外部 API（已配的兼容 OpenAI 协议的端点），不在本地跑模型权重。
- ❌ **不做学术站全文批量抓取**。合规红线。

第二版要演进 SaaS 时，哪些约束放开、按什么顺序放开，单列在演进路线文档里，本文件不展开。
